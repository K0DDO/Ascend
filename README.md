# Ascend

Personal learning system for a programming mentorship platform.

**LEARN → REMEMBER → UNDERSTAND → PROVE → GET HIRED**

Mobile-first Flutter client + Python FastAPI backend. Not an Anki clone — spaced repetition with a two-button UX (`Повторить` / `Знаю`), structured knowledge base, entitlements, offline-first encrypted content, and (later) grounded AI interviews.
